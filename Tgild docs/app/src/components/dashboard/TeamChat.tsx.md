# `app/src/components/dashboard/TeamChat.tsx` — Team Chat (~1150 lines)

- **Purpose**: Full-featured team/group chat interface with message history, attachments, mentions, search
- **Props**: `teamId`, `teamName`, `members`, `onBack`
- **State**:
  - `messages` — message array (paginated)
  - `newMessage` — text input
  - `attachedFiles` — files to send
  - `replyingTo` — reply context
  - `editingMessageId` — edit mode
  - `pinnedMessages` — pinned message list
  - `searchQuery` — message search
  - Various UI states (loading, error, empty)
- **Features**:
  - **Message list**: Scrollable with auto-scroll to bottom on new messages, date separators, pagination (load older on scroll up)
  - **Send message**: Text input + send button, Enter to send, Shift+Enter for newline
  - **File attachments**: Upload button → file dialog → attaches to message
  - **Reply**: Click reply on message → reply bar appears above input
  - **Edit**: Click edit on own message → input pre-filled
  - **Delete**: Delete own messages with confirmation
  - **Mentions**: `@` autocomplete with member list
  - **Pin/Unpin**: Pin messages to top of chat
  - **Search**: Search input → filters messages
  - **Forward**: Forward messages to other chats
  - **Mark as read**: Auto-mark on view
  - **Media display**: Inline image/video/file previews
  - **Typing indicator**: Shows when members are typing
  - **Message reactions**: Emoji reactions
- **Data flow**: `useQuery(['messages', teamId])` for message list, `useMutation` for send/edit/delete, Tauri events for real-time updates

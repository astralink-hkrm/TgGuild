# `app/src-tauri/src/commands/fs.rs` — Filesystem Commands (~2300 lines)

- **Purpose**: All virtual filesystem operations — the largest Rust file
- **Imports**: grammers-client, grammers-tl-types, tokio, tauri, serde_json, std::fs, std::path, chrono, uuid, sha2
- **Commands**:
  - `cmd_get_folders(state)` → scans all Telegram dialogs, looks for messages with `TGGuild_FOLDER_V1:` or `TGGUILD_TREE_V1:` prefix, rebuilds folder tree. Populates `peer_cache` as side effect. Returns `Vec<FolderMetadata>`
  - `cmd_get_files(folder_id, state)` → gets messages in the folder's chat, filters out folder markers, parses `TGGuild_FILE_V1:` metadata, returns `Vec<FileMetadata>`. Emits `get-files-progress` events
  - `cmd_get_folder_tree(state)` → builds hierarchical `FolderTreeNode` from folder markers
  - `cmd_get_file(folder_id, message_id, state)` → gets single file metadata by message ID
  - `cmd_create_folder(name, parent_id, state)` → sends a new message with `TGGuild_FOLDER_V1:` prefix in the parent folder's chat (or Saved Messages). Returns new FolderMetadata
  - `cmd_rename_file(message_id, folder_id, name, state)` → edits message text to update `TGGuild_FILE_V1:` metadata JSON
  - `cmd_rename_folder(folder_id, name, state)` → similar, updates folder marker message text
  - `cmd_delete_file(folder_id, message_id, state)` → deletes the Telegram message containing the file
  - `cmd_delete_folder(folder_id, state)` → deletes folder marker message + recursively deletes all files/subfolders
  - `cmd_move_to_folder(folder_id, target_folder_id, state)` → moves a virtual folder (updates parent_id in message text)
  - `cmd_move_file_to_folder(message_id, source_folder_id, target_folder_id, state)` → moves file to another folder (re-maps chat/message association)
  - `cmd_upload_file(folder_id, file_path, message_text, state, app_handle, bandwidth)` → reads file from disk, splits into chunks (smart chunking), uploads via grammers `client.send_message()`, emits `upload-progress` Tauri events with progress/speed/ETA, marks bandwidth usage, creates `TGGuild_FILE_V1:` marker message. Handles cancellation via `cancelled_transfers` set
  - `cmd_download_file(message_id, folder_id, state, app_handle, bandwidth)` → downloads file from Telegram, writes to appdata temp directory, emits `download-progress` events with chunk-level diagnostics (speed per chunk), marks bandwidth usage. Handles cancellation. Returns file path
  - `cmd_get_thumbnail(folder_id, message_id, state, app_handle)` → generates thumbnail for image files (resized), returns cached path
  - `cmd_get_preview(folder_id, message_id, state, app_handle)` → returns preview data for supported file types
  - `cmd_search_files(query, state)` → searches file/folder names across all folders, returns matching results
- **Smart chunking**: Upload strategy — splits files into optimal chunk sizes based on total file size (adaptive for Telegram's 2GB limit)
- **Progress events**: `app_handle.emit("upload-progress", payload)` and `emit("download-progress", payload)` for real-time UI updates
